# Meta-Ads-Performance-Dashboard-Power-BI-
## Project Overview

This project is an interactive **Power BI dashboard** developed to analyze and monitor the performance of Meta (Facebook and Instagram) advertising campaigns. The dashboard provides a comprehensive view of campaign performance by tracking key digital marketing metrics, enabling businesses and marketing teams to evaluate campaign effectiveness, optimize advertising spend, and make data-driven decisions.

The project simulates a real-world business scenario where multiple advertising campaigns generate large volumes of performance data. The goal was to transform raw marketing data into meaningful insights using Power BI, Power Query, and DAX.

---
## Business Problem

Marketing teams invest significant budgets in online advertising, but without proper reporting it becomes difficult to identify:

* Which campaigns generate the best results.
* Where advertising budget is being wasted.
* Which audience segments perform better.
* How campaign performance changes over time.
* Which marketing objectives deliver the highest return.

This dashboard was created to answer these business questions through interactive data visualization.

---
## Objectives

 Analyze overall Meta advertising performance.
 Monitor important marketing KPIs.
 Compare campaign performance across different dimensions.
 Identify high-performing and low-performing campaigns.
 Support data-driven marketing decisions.

## Dashboard Features

The dashboard includes interactive visualizations for:

* Total Impressions
* Reach
* Clicks
* Link Clicks
* Click-Through Rate (CTR)
* Cost Per Click (CPC)
* Cost Per Mille (CPM)
* Total Spend
* Conversions
* Return on Ad Spend (ROAS)

Interactive slicers allow users to filter the dashboard by:

* Campaign
* Campaign Objective
* Date
* Audience
* Placement

Dynamic KPI cards automatically update based on user selections, providing a flexible and interactive reporting experience.

---
## Data Preparation

Before building the dashboard, the dataset was cleaned and transformed using **Power Query**. The preparation process included:

* Removing duplicate records
* Handling missing values
* Standardizing data formats
* Creating calculated columns
* Preparing the dataset for analysis

---
## DAX Measures

Several DAX measures were created to calculate important marketing KPIs dynamically, including:

* Total Spend
* Total Clicks
* CTR
* CPC
* CPM
* Conversion Rate
* ROAS
* Total Reach
* Total Impressions

These measures allow the dashboard to update automatically based on applied filters.

---
## Key Business Insights

Analysis of the dashboard helped identify several valuable insights, including:

* High-spending campaigns did not always generate the highest conversions.
* Certain campaigns achieved stronger ROAS despite lower advertising budgets.
* Click-Through Rate varied significantly across campaign objectives.
* Some campaigns showed high impressions but relatively low engagement, indicating opportunities for optimization.
* Interactive filtering made it easy to compare campaign performance across different time periods and marketing objectives.
